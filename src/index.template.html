使い方と注意事項

ヘッダーのENで英語に、JAで日本語に切り替えます。

基本操作

  1. 基準画像にBefore、比較画像にAfterの写真を追加します。
  2. 「比較する」を押すと、2枚の写真で共通する目印を探して自動でズレを合わせます。
  3. 赤い表示が多すぎる・少なすぎる場合は、結果のすぐ下にある「結果を調整」を使います。
  4. まず「変化を見る」で確認します。「次の変化」「前の変化」で順に拡大でき、「表示を戻す」で全体に戻ります。

プライバシー

画像と比較結果はこの端末内だけで処理されます。このアプリから画像をアップロードせず、比較に必要な機能も実行時に外部から読み込みません。

うまくズレを合わせにくい写真

  • 撮影位置が大きく異なり、手前と奥の物でズレ方が大きく違う写真
  • 無地の壁など、対応付けられる模様や角がほとんどない写真
  • 大部分が別の物で隠れている、または構図が大きく変わった写真
  • 強い影、照明、反射の変化は「物の変化」として検出される場合があります。

注意事項

  • 動作を安定させるため、写真は選んだ「写真の細かさ」に合わせて縮小して比較します。保存画像も同じ大きさです。
  • 自動で見つけた変化は確認の補助です。工事・品質検査など重要な判定では元画像も確認してください。
  • 対応画像を選び直すと古い結果はすぐ消え、読み込み後に再比較が必要です。キャンセルや形式・サイズの不適合では結果は残ります。
  • 大きな写真は端末のメモリを多く使います。スマホで不安定な場合は「写真の細かさ」を「軽め」にしてください。
